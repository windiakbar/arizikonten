Instructions Google Apps Script (GAS):

  1. Buka Google Spreadsheet Batik Arizi Anda: Buka Spreadsheet.
  2. Klik menu Ekstensi > Apps Script.
  3. Paste kode dibawah ke dalam file Code.gs.
  4. Klik Deploy > New Deployment > Web app.
  5. Atur Who has access ke Anyone.
  6. Salin URL Web App dan paste ke variabel GAS_WEBHOOK_URL di kode HTML ini.
